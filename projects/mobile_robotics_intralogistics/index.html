Mobile Robot Development for Intralogistics

A LEGO-based mobile robot on a Raspberry Pi that navigates a model warehouse and carries out logistics tasks. It won 1st place in the course challenge.

  • Raspberry Pi
  • Dijkstra
  • OpenCV
  • PID
  • MQTT
← All projects Get in touch

What I built

  • Planning: Dijkstra-based global path planning for efficient routes through the warehouse.
  • Perception: an OpenCV pipeline for object detection.
  • Control: PID motor control for the differential drive, for stable trajectory tracking.
  • Coordination: MQTT-based communication for dynamic task allocation and human–robot interaction.

Result

The robot achieved 1st place in the course challenge evaluation.
